User guide
==========

This guide follows what you do with a logger, from the first line to a production setup. Each page starts with the
smallest example that works and adds one idea at a time. Every example on these pages was run, and the output shown is
what it printed.

If you have five minutes, read :doc:`hello_world` and :doc:`console`. They are all you need to start. The other pages
are there for when you need them.

The detailed reference for each subject, such as durable delivery, SIEM and OpenTelemetry, is in :doc:`../getting_started`,
and every class and function is in :doc:`../api_reference`.
